FEATURES

Built for a small crew, not a crowd

SAF SMP isn't trying to be a network. It's one curated world, set up so it's actually still standing next time you log in.

Land Claims & Anti-Grief

FTB Chunks lets everyone claim and protect their base. Go build somewhere without worrying about coming back to a hole in the ground.

One Modpack, Same World

Everyone runs the same curated pack. Install it once through the Modrinth App and you're dropped straight into the same world as the rest of us.

More to Explore

New biomes, tools, and mobs layered over the survival game you already know — enough to make exploring worth it again.

Friendly by Default

This is a friends-and-friends-of-friends server, not a public free-for-all. Show up decent and you'll fit right in.

Backed Up, Not Fragile

The world gets backed up regularly, so a bad crash or a rough mod update doesn't mean losing what you've built.

Events, When We Feel Like It

Seasonal builds, group projects, and the occasional boss fight whenever enough of the crew is online for it.

HOW TO JOIN

The recipe for getting in

Like any good recipe, you just need the right ingredients. This one's shapeless — the order doesn't matter, as long as you've got all three.

You're in

  1. Grab the modpack

    Download the SAF SMP modpack below. It's the exact pack everyone else on the server is running, so keep it as-is.

    Download the Modpack

  2. Get the Modrinth App

    If you don't already have it, install the Modrinth App — the official Modrinth launcher. It's built to import modpacks like this one in a couple of clicks.

    Get the Modrinth App

  3. Import the pack. Open the Modrinth App, choose Import, and select the file you just downloaded. It'll pull in the mods, configs, and the right Minecraft version automatically — no manual setup needed.

  4. Launch it once. Start the modpack from the Modrinth App before doing anything else, so everything finishes installing.

  5. Add the server

    In-game, go to Multiplayer → Add Server, and paste in the address:

    safsmp.online

  6. Join in. Hit Join Server, wait for the world to load, and say hello in chat.

GROUND RULES

Keep it simple

Nothing complicated — just enough so the world stays good for everyone.

  • 01

    Claim your base with FTB Chunks. Anything outside a claim is fair game, so don't leave something valuable unclaimed.

  • 02

    No griefing, stealing, or PvP unless everyone involved has actually agreed to it first.

  • 03

    Keep the modpack as given. Extra mods or resource packs can desync you from the server or cause crashes.

  • 04

    Report bugs and dupes instead of using them. We'd rather fix it than ban someone over it.

  • 05

    Be a decent hang. It's a small server — treat it like you're a guest in someone's house, because you are.
